# Data card

Two distinct datasets are bundled. The synthetic stream has240 daily windows, original invented entity/event metadata, seed73129, six fixed topic classes, source/duplication/dropout controls, and two injected composition breaks. The evaluated dashboard begins after a30-day frozen reference. The source generator fully reconstructs event records. Licence: CC0 synthetic metadata.

The real sample contains four GDELT2 Events archives, one01:30UTC interval on each of October10–13,2026, 3,414 provider IDs, exact61-field metadata and source citations. Scope: machine-extracted sociopolitical CAMEO records. All provisional. Licence/attribution: The GDELT Project dataset terms; linked publisher content has separate rights. No article bodies fetched.

Neither dataset is a census of world events. Source, language, geographic and newsworthiness selection bias are material. Real labels are actor/action code renderings, not article headlines. Provider record deduplication does not establish true-event uniqueness. See docs/data_sources_and_rights.md and per-archive provenance.
