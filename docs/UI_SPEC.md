# Interface contract

Dark observatory design with ivory text and amber signals. Four views: synthetic Observatory, Methodology, synthetic Event log, real GDELT sample. Every synthetic screen declares its mode; real metadata declares its small sampled scope and provisional verification status.

The date slider, previous/next and replay select one exact closed daily observation. Timeline range controls select7/30/90/all windows; no fake24-hour intraday display. Reference controls affect JSD, transport and topic-share reference bars together. Predictive surprise remains a separately defined historical rank. Missing data and low history display unavailable, not zero.

Coverage warnings show source/sample issues and suppression. Domain contributions describe distribution terms without causal claims. Forecast uncertainty is expandable and conditional, with an unvalidated coverage caveat. Scenario impact stays explicitly not implemented. Event dialogs show source diversity, provenance and limitations. Real records have paginated actor/action metadata and safe source links, not invented headlines.

Keyboard controls, visible focus, modal close behavior, reduced-motion handling, responsive layout, empty/error/retry states and DOM contracts are implemented. Native rendered browser QA is separately required before claiming cross-browser visual validation.
